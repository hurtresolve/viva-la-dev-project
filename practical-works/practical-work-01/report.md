 1. Формирование команды и распределение ролей
В рамках выполнения командного проекта была сформирована команда, участники которой получили различные профессиональные роли. Распределение обязанностей выполнено с учётом характера выполняемых задач и необходимости разделения ответственности между участниками проекта.
Каждая роль отвечает за отдельное направление работы над программной системой. Такое распределение позволяет разделить задачи между участниками и организовать совместную работу команды.



2. Коммуникация и правила взаимодействия
Для взаимодействия участников команды было принято решение создать чат в Telegram. Он используется для обсуждения проекта, обмена информацией, постановки задач и оперативного решения возникающих вопросов:
1.	Все основные вопросы по проекту обсуждаются в общем чате.
2.	При постановке задачи необходимо сформулировать её понятным образом и указать ожидаемый результат.
3.	Участники своевременно сообщают о выполнении задач.
4.	При возникновении проблемы участник сообщает о ней команде, а не оставляет задачу без объяснения.
5.	Важные решения по проекту обсуждаются совместно.
6.	Лидер команды координирует выполнение задач и следит за соблюдением договорённостей.
7.	При необходимости участники консультируются друг с другом в соответствии с распределёнными ролями.
8.	Сроки выполнения задач согласовываются командой заранее.

 5. Взаимодействие участников команды
Взаимодействие участников команды строится на распределении задач между различными профессиональными ролями.
Лидер команды координирует работу участников, распределяет задачи и контролирует соблюдение сроков. Исследователь передаёт результаты исследования специалисту по данным и архитектору. Специалист по данным подготавливает необходимую информацию для дальнейшей работы. Архитектор согласовывает структуру системы с программистом и учитывает результаты исследования.
Программист реализует архитектурные решения и взаимодействует со специалистом по тестированию. Тестировщик проверяет разработанное ПО, сообщает о выявленных ошибках программисту и передает результаты тестирования лидеру. Все участники используют общий Telegram—чат для обсуждения задач, обмена информацией и принятия важных решений.
