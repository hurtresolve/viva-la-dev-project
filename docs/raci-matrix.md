## 4. Распределение ответственности в Git

На основе разработанной матрицы RACI, команда закрепляет за каждым участником следующие обязанности в рамках работы с удаленным репозиторием:

* **Создание и настройка репозитория**
  * **A (Ответственный):** Андрианов Е. (Руководитель)
  * **R (Исполнитель):** Андрианов Е. (Руководитель) / Панферова А. (Архитектор)

* **Поддержание структуры папок и файлов**
  * **A (Ответственный):** Андрианов Е. (Руководитель)
  * **R (Исполнители):** Все участники команды (Лавренова А., Максимов Е., Маркелов Г., Андрианов Е., Панферова А., Новиков Б. — каждый в рамках своих рабочих разделов).

* **Написание отчётов по практическим работам**
  * **A (Ответственный):** Андрианов Е. (Руководитель)
  * **R (Исполнители):** Все участники команды согласно своим ролям в матрице RACI.

* **Внесение коммитов с осмысленными сообщениями**
  * **A (Ответственный):** Андрианов Е. (Руководитель)
  * **R (Исполнители):** Каждый участник команды лично отвечает за оформление своих изменений.

* **Проверка пул-реквестов (Pull Request)**
  * **A (Ответственный):** Андрианов Е. (Руководитель)
  * **R (Исполнители):** Андрианов Е. (Руководитель) / Панферова А. (Архитектор)

* **Слияние веток (merge)**
  * **A (Ответственный):** Андрианов Е. (Руководитель)
  * **R (Исполнитель):** Андрианов Е. (Руководитель)

* **Резервное копирование и поддержание актуальности репозитория**
  * **A (Ответственный):** Андрианов Е. (Руководитель)
  * **R (Исполнители):** Все участники команды (путем своевременного выполнения команд `git pull` и `git push`).
